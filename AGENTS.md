### Key Decisions
- **Essentiel now includes everything the Command Center shows** (achats=purchases, stock, tresorerie=treasury) — guard pages stay but no longer trigger for those modules. Business/Premium keep accounting/rh as differentiators; `organization_modules.enabled` (NOT `is_enabled`) is the stored column.
- **CSS semantic variables are the single source of truth** for theme colors; legacy `bg-white`/`text-slate-*`/`border-*`/`shadow-*` classes are remapped to tokens in `globals.css` (compatibility layer) so un-refactored screens adapt to light AND dark automatically.
- **Light = default on load** (defaultTheme="light", enableSystem=false); dark only via header toggle, persisted in `felexia-theme` localStorage; no global `color-scheme: dark`, no hydration flash (provider + `suppressHydrationWarning` + Toggle uses `useSyncExternalStore` for mounted, NOT `useState`+`useEffect` which violates `react-hooks/set-state-in-effect`).
- Theme toggle stays visible on mobile; sidebar active item = card bg + primary left bar; gold/accent reserved for small brand touchpoints (logo, avatar), never big CTAs (CTAs = `var(--primary)`).
- Deliberately dark regardless of theme: landing hero `app/page.tsx`, `mobile-app-banner`, print views (`#2d2490`), modal scrims.
- **Unique default plan key = `essentiel`** (never `essential`/`Business`); Business/Premium only via explicit upgrade. `normalizePlanCode` maps `pro`→premium.
- **`upsertTrialForPlan` is insert-only** when no subscription exists — never overwrites an existing org's plan, protecting paying orgs.
- **No global redirect to `/parametres/abonnement`** for expired/canceled access (`resolve-onboarding-redirect` returns null); handled locally by `ModuleUpgradePage` / banners.
- **Canonical guard** = `requireActiveSubscription` (`src/lib/auth/require-subscription.ts`); `subscription-guard.tsx` is a re-export only.
- Migration 089 adds `products` to `modules_catalog`; `upsertModulesForPlan` filters out keys missing from the catalog.
- Business trial helpers (`ensureBusinessTrialAndModulesNoRevalidate`, `startBusinessTrialAndEnableModules`, `createDefaultBusinessTrial`) remain for explicit Business upgrade paths only.
- synta-iq is the single company lookup source: clean JSON, no scraping, no cheerio (dependency removed)
- `past_due` = grace period; only `canceled` blocks access
- `canAccessApp()` is single source of truth for subscription access
- Cache never returns "not_found" — always re-queries providers
- Invitation acceptance is token-gated via security definer RPCs (migration 088), never via RLS grants to anon
