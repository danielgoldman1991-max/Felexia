# OASIS UBL 2.1 schema bundle

Official unmodified files retrieved from https://docs.oasis-open.org/ubl/os-UBL-2.1/xsd/. Version: OASIS Standard, 4 November 2013. Copyright and licensing notices remain in each schema, including W3C notices in XMLDSig/XAdES components. See https://www.oasis-open.org/policies-guidelines/ipr and the official release documentation.

The manifest pins all fifteen transitive Invoice/CreditNote XSD dependencies by SHA-256. No runtime network resolution is allowed. UBL-xmldsig-core-schema-2.1.xsd contains an internal DTD in the trusted official schema; untrusted invoice XML always rejects DTDs and entity declarations.

This generic technical profile does not claim DGI acceptance, certification, qualified signature or regulatory compliance.
